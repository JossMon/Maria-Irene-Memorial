# María Irene Bedoya Ayala — Memorial Website

This is a static memorial website designed to publish with GitHub Pages. No build tools are required.

## Preview it on your computer
Open `index.html` in a web browser. All images, styles, and scripts are included in this folder.

## Publish with GitHub Pages
1. Sign in to GitHub and create a new public repository. A simple name such as `maria-irene` works well.
2. Upload **all files and folders inside this project** to the repository, including the `assets` folder.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then Save.
6. GitHub will show the site URL after deployment finishes.

Typical URL: `https://YOUR-USERNAME.github.io/maria-irene/`

## Adding more photos later
Add new images inside `assets/images/`, then update `index.html` to place them in the relevant section. The current site is intentionally structured so new timeline items, memory cards, and gallery tiles can be added without rebuilding the design.

## Files
- `index.html` — content and page structure
- `styles.css` — design and responsive layout
- `script.js` — language toggle, scroll reveals, image lightbox
- `assets/images/` — memorial and family photos

## Design notes
The palette uses cream, forest green, sage, olive, and warm gold. The site is bilingual (Spanish/English), mobile responsive, and contains no third-party libraries.
